# Files this repo mirrors from the dotfiles repo. Read by
# scripts/dotfiles-drift.sh (make dotfiles-drift, dotfiles-select, sync-dotfiles).
#
# Format: group|item|label|default|install file|dotfiles file|stop|ignore
#   default  on or off: checked until `make dotfiles-select` saves your ticks
#   stop     compare only the lines of the install file above the first line
#            that starts with this text (the install repo's own tail, kept on
#            sync); - for none
#   ignore   extended regex: lines matching it on either side are left out of
#            the comparison (headers that differ on purpose); - for none. It is
#            the last field, so it may contain |. A file with an ignore regex is
#            check-only: sync would drop the install repo's own lines, so merge
#            it by hand.
#
# Group and item form the keys in ~/.local/bootstrap/dotfiles-drift, so
# renaming one loses its saved tick.
